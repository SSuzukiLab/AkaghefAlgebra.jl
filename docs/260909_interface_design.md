# 代数計算インターフェースの設計方針

本書は代数計算インターフェースの設計方針の正本である。目標とする契約を述べるものであり、全 API の実装完了を意味しない。

## 代数と出力

数学的な演算の公開入口は、対象と代数データから値を返す。出力の係数領域と型は代数に依存してよい。代数データには値を決めるパラメータと規約を保持し、計算戦略とは区別する。指定した生成元を結果から識別する必要がある場合、その指定も出力に保持する。

## 構築・簡約化・評価・正規化

式の構築は数学的定義を表現する。簡約化は明示された仮定の下で値を保存する。具体評価は残った有限和などを係数領域で計算する。最終正規化は根の具体的指定などを反映し、比較可能な係数表現を返す。

通常の入口はこれらを合成する。途中に介入する利用者にも同じ部品を公開し、入力を破壊せず新しい結果を返す。戦略は明示的に渡せるようにする。適用可能な正しい戦略間で最終値は変わらず、残余式と計算量は変わってよい。

共通化するのは呼出しの役割と値保存の契約であり、全代数に同一 AST や簡約規則を要求しない。簡約化が未対応なら元の式を保持する。具体評価が未完了なら未完了として通知し、残余式を完成した値として返さない。

## 値がないとき

値を 1 つ返す公開入口は、値を返すか例外を投げる。戻り値に「値なし」を混ぜない。方程式の解の種類、外部ツールの有無、探索の終了状態のように、状態そのものが答えである関数は、状態を値として返す。

値を返せなかった結果は次の 4 種類に分ける。

| 種類 | 主張すること | 例 | 保存 |
|---|---|---|---|
| 未定義 | 定義が入力を除外している | U(R) の特異なトレース行列 | 定義の版を添えて結果として保存してよい |
| 未計算 | 何も主張しない。値の非存在も意味しない | 時間切れ、予算切れ、未実装の範囲、外部ツールなし、検出した overflow | 実行記録にだけ残す |
| 入力不正 | データが対象の型をなしていない | Gauss word の訪問の欠落 | 実行記録にだけ残す |
| 不具合 | この実行を信用できない | 上記以外の例外、`1//0`、`NaN` | その実行をデータとして保存しない |

定義を変えない限り、計算資源と実装をいくら足しても値が出ないものを未定義とする。値があるか分からないものは未計算とする。有効な入力が定義の前提を満たさない場合は未定義、データ自体が壊れている場合は入力不正とする。

未定義と呼ぶには次の 3 つを揃える。

- 定義文に条件が書かれている。
- コードがその条件を名指しし、厳密計算で判定する。
- 実例のテストがある。

厳密値は `BigInt` や厳密有理数のように回り込まない型で計算する。回り込んだ整数や `1//0` を値として返さない。

### Julia での表し方

未定義は `UndefinedError(条件, 証人)`、未計算は `NotComputedError(理由, 予算)` を投げる。条件と理由はシンボルとし、条件は不変量ごとの文書に書く。両方の型は `AkaghefAlgebra` に置く。

`DomainError` は Base も投げるので、未定義の印に使わない。`ArgumentError` は引数の誤用と入力の検査に使い、予算切れや未実装の範囲には使わない。`nothing` は理由を持てないので、未定義と未計算に使わない。`missing` は「値はあるが照合先がない」場合に限る。

### 表とまとめての計算

- 行の作成または行の検査に失敗したものは、入力不正として記録する。行の検査関数は呼び出し側が渡す。
- 各列は、許す未定義の条件を宣言する。宣言にない条件は不具合とする。
- セルは `UndefinedError` と `NotComputedError` だけを未定義と未計算として受ける。他の例外はすべて不具合として記録し、計算を続ける。`InterruptException` だけは止める。
- 返った値も検査し、有限でないものは不具合とする。
- 種類ごとの件数を常に表示する。不具合が 1 件でもあれば、最後に例外を投げ、データとして保存しない。
- 時間切れは、アルゴリズムが自分で期限を確認する方式に限る。確認点のない関数は、セルの途中では切れない。
- 未計算を含む表を、値の非存在の根拠にしない。

既存の `ArgumentError` は一括で書き換えない。表に入れる列から順に移行する。移行前の例外は不具合として見える。

## 等価性と根の指定

記号式の構造的一致と、評価後の数学的な値の一致を区別する。厳密値は係数領域の正規形で比較する。数値近似は明示的な変換とする。

Taft では簡約化・残余和評価を N のみに依存させ、最後に q = ζ_N^M を反映する。出力 `Cyclotomic{N,M}` は根の指定を保持し、保存係数は標準生成元 ζ_N 基準に統一する。M の置換は一度だけ行い、表示・数値化・再正規化で重ねない。公開型は内部の計算用 `TaftExact.Cyclotomic{N}` を包む形で実装している。

同じ N の値は M が異なっても標準係数で比較できる。根指定の一致は別に調べる。通常の演算は同じ N、M 内で行い、異なる指定間の演算には明示的な変換を要求する。一般の異なる係数領域間の自動変換は要求しない。

## 所有境界

代数側は係数領域、演算、簡約化・評価・正規化を担当する。Topology 側は入力図の契約と不変量の構築・接続を担当する。不変量固有の仮定を代数一般の条件として追加しない。

利用側の契約は [Topology の MST インターフェース](../../topology.jl/docs/260909_mst_interface.md)、Taft 固有の移行・受入条件は [PJ260830 の要件書](../../../threads/PJ260830/docs/reports/260909_mst_interface_requirements.md) を参照する。共通方針を変更するときは本書を更新し、利用側では重複定義しない。
